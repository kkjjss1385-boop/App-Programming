# [중간평가] 1~7주차 학습 점검 및 보완 계획

## 1. 1~7주차 단원별 학습 점검

| 주차 | 핵심 개념 | 이해도 | 보완할 점 및 계획 |
| --- | --- | --- | --- |
| 1~2주차 | Dart 기초 문법 & Flutter UI 위젯 기초 | 보통 | `StatefulWidget` 생명주기(`initState`, `dispose`) 개념 재검토 |
| 3~4주차 | 레이아웃 구축 & 상태 관리 기초 | 양호 | `ListView.builder`를 활용한 가변 리스트 렌더링 방식 복습 |
| 5~6주차 | 비동기 처리(`Future`/`async`/`await`) & JSON 파싱 | 보완 필요 | `dart:convert` 모듈을 이용한 JSON 디코딩 시 `try-catch` 예외 처리 실습 |
| 7주차 | 앱 기획, 컨텍스트 엔지니어링, AC 정의 | 양호 | 인수 조건(AC)에 예외 및 실패 케이스를 포함하는 작성법 정립 |

## 2. 중간평가(30문항) 대비 복습 계획
- **목표**: 개념 암기를 넘어 화면/코드/기획 상황 적용 문제 해결력 확보
- **주요 복습 영역**:
  1. **Dart 문법**: Null Safety, 비동기(`Future`, `Stream`), Collection 문법
  2. **Flutter 위젯 및 상태**: `Stateless` vs `Stateful`, `setState` 동작 원리
  3. **비동기 API 처리**: HTTP/API 응답 처리, JSON 파싱 (`fromMap`/`toMap`)
  4. **컨텍스트 엔지니어링**: AI 시스템 프롬프트 작성 구조 및 JSON 응답 강제 기법
