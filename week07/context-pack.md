# [작업자료] 다음 작업 컨텍스트 팩

## 1. 다음 작업 하나 선택
- **작업 목표**: Gemini Vision API를 활용한 '옷 사진 카테고리/색상 자동 인식 및 예외 처리' 구현 계획 수립
- **선택 근거**: 앱의 첫 핵심 경험인 '옷 등록'의 정확도와 사용자 예외 상황 대응을 결정짓는 최우선 과제임.
- **제약 조건**:
  - 외부 백엔드 서버 없이 Flutter `google_generative_ai` 패키지로 직접 연동
  - API 응답은 `application/json` 형식으로 받으며, 비의류 이미지 처리 로직 포함
- **현재 상태**: 기획 및 프롬프트 명세 작성 완료, 코드 구현 전
- **확인 기준 (AC)**:
  - 의류 이미지 전달 시 정상 JSON 반환
  - 비의류 이미지 전달 시 `{"error": "not_clothing"}` JSON 반환
