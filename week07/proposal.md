# [제안서] AI 개인 퍼스널 쇼퍼 & 스타일리스트 앱 (ClosetAI)

## 1. 문제와 첫 사용자 선택
- **사용 상황**: 매일 아침 출근/등교 준비 시 옷장 앞에서 어떤 옷을 조합해 입어야 할지 고민하며 시간을 허비함.
- **불편 사항**: 옷은 많지만 적절한 조합을 모르고, 날씨나 TPO(시간·장소·상황)에 맞지 않는 옷을 선택해 불편을 겪음.
- **첫 사용자**: 출근 시간을 단축하고 자신에게 어울리는 코디를 원하지만 패션 감각이 부족한 2030 직장인 및 대학생.
- **핵심 가치**: 내가 보유한 옷만으로 날씨와 TPO에 맞는 최적의 코디를 AI가 제안하여 아침 준비 시간을 단축하고 스타일 만족도를 높임.

## 2. MVP 범위 및 제약 결정

| 구분 | 기능 및 제약 | 결정 이유 |
| --- | --- | --- |
| **필수 (In-Scope)** | - 옷 사진 업로드 및 Gemini Vision AI 카테고리/색상 자동 인식<br>- 내 옷장 목록 조회, 빈 상태 안내 및 선택 삭제<br>- 날씨/TPO 조건 선택 시 보유 옷 기반 AI 코디 추천 | MVP의 핵심 가치인 '내 옷 등록 + 맞춤 코디 추천' 흐름을 검증하기 위한 최소한의 구성 |
| **보류 (Deferred)** | - 착장 피드백 (전신 사진 분석 및 점수 산정)<br>- OOTD 캘린더 (달력 기반 착장 기록) | 1차 MVP 동작 및 검증 이후 2차 고도화 단계에서 추가 |
| **제외 (Out-of-Scope)**| - 사용자 회원가입/로그인 (로컬 저장소 SharedPreferences로 대체)<br>- 외부 쇼핑몰 결제 연동 및 유료 백엔드 구축 | 과제 제약사항(로그인/결제/외부 서버 구축 금지) 준수 |

- **저장 방식**: 로컬 기기 내 `SharedPreferences` 및 로컬 파일 시스템 저장
- **실행 환경**: Flutter (Android / iOS / Web 호환)
- **개인정보 범위**: 개인식별정보(이름, 전화번호 등) 수집 없음. 사용자 기기 내 로컬 이미지 데이터만 처리

## 3. 핵심 흐름, 데이터, 앱 인수 조건 (App AC)

### 핵심 화면 흐름
1. **내 옷장 화면**: 등록된 옷 카드 목록 조회 (빈 상태 시 '옷 등록' 안내 노출)
2. **옷 등록 화면**: 사진 업로드 → Gemini Vision AI 분석 → 카테고리·색상 확인/수정 후 저장
3. **AI 추천 화면**: 날씨/TPO 선택 후 추천 받기 버튼 클릭 → AI 추천 조합 및 코디 팁 확인

### 핵심 데이터 구조
- `ClothItem`: `id` (String), `imageUrl` (String), `category` (String), `color` (String), `season` (List<String>)
- `RecommendationResult`: `selectedItemIds` (List<String>), `title` (String), `advice` (String)

### 앱 인수 조건 (App AC)

> **현재 검증 상태**: 기획 단계이므로 전체 앱 AC의 상태는 `미실행`입니다.

| ID | 구분 | 조건 및 행동 | 기대 결과 | 확인 방법 | 현재 상태 |
| --- | --- | --- | --- | --- | --- |
| **APP-AC1** | 정상 입력 | 옷 사진을 업로드하고 분석을 요청한다. | Gemini Vision이 `category`, `color` 등을 정확한 JSON으로 반환해 입력 폼에 채운다. | 옷 사진 업로드 후 결과 폼에 데이터 자동 등록 확인 | 미실행 |
| **APP-AC2** | 잘못된 입력 | 옷이 아닌 사진(예: 음식, 풍경)을 업로드하고 분석을 요청한다. | AI가 비의류 사진임을 감지하고 "옷 사진을 올려주세요" 에러 메시지를 표시하며 재업로드를 유도한다. | 풍경 사진 업로드 시 예외 처리 스낵바/경고창 노출 확인 | 미실행 |
| **APP-AC3** | 빈 상태 | 옷장에 옷이 하나도 없는 상태에서 추천 화면에 진입한다. | "등록된 옷이 없습니다. 먼저 옷을 등록해주세요" 안내 문구와 '옷 등록하기' 버튼을 노출한다. | 앱 초기 실행 후 옷장 및 추천 탭 비어있는 상태 확인 | 미실행 |
| **APP-AC4** | 실패/재시도 | 네트워크 오류나 API 키 오작동으로 AI 추천 요청이 실패한다. | "네트워크 연결을 확인해주세요" 문구와 함께 [다시 시도] 버튼을 제공하며, 재시도 클릭 시 요청을 재수행한다. | 오프라인 상태에서 추천 요청 시 재시도 UI 작동 확인 | 미실행 |
