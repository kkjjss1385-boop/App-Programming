# CONTEXT_PACKET.md

## 1. 목표
- Todo 아이템의 완료/취소 토글 기능을 구현하고, 입력에 따른 상태 변경과 UI 반영을 검증한다.

## 2. 현재 코드
```dart
import 'package:flutter/material.dart';

void main() => runApp(const MyApp());

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return const MaterialApp(
      home: TodoScreen(),
    );
  }
}

class TodoScreen extends StatefulWidget {
  const TodoScreen({super.key});

  @override
  State<TodoScreen> createState() => _TodoScreenState();
}

class _TodoScreenState extends State<TodoScreen> {
  // 원본 상태 (State)
  bool _isCompleted = false;

  // 계산된 값 (Derived Value) - AC4 준수: 별도 변수에 중복 저장하지 않음
  String get _statusText => _isCompleted ? "완료됨" : "미완료";
  Color get _buttonColor => _isCompleted ? Colors.green : Colors.grey;

  void _toggleStatus() {
    setState(() {
      _isCompleted = !_isCompleted;
    });
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('5주차 과제 - Todo 토글')),
      body: Center(
        child: Column(
          mainAxisAlignment: MainAxisAlignment.center,
          children: [
            Text('현재 상태: $_statusText', style: const TextStyle(fontSize: 24)),
            const SizedBox(height: 20),
            ElevatedButton(
              style: ElevatedButton.styleFrom(backgroundColor: _buttonColor),
              onPressed: _toggleStatus,
              child: Text(_isCompleted ? '취소하기' : '완료하기'),
            ),
          ],
        ),
      ),
    );
  }
}
```

## 3. 구현 근거 및 제약사항
- 외부 상태관리 패키지(Provider, Bloc 등) 및 서버 연동 없이 Flutter 순수 `setState`만을 활용한다.
- Windows 일반 명령 프롬프트 환경에서 `flutter analyze`를 통과해야 한다.

## 4. 인수 조건 (Acceptance Criteria)
- **AC1**: 초기값(`_isCompleted = false`)과 첫 화면('현재 상태: 미완료', '완료하기' 버튼)이 일치한다.
- **AC2**: 버튼 입력 1회 시 상태가 `true`로 바뀌며 화면이 '완료됨', '취소하기' 버튼(초록색)으로 함께 바뀐다.
- **AC3**: 다시 버튼을 누르는 역동작 시 원래의 '미완료' 상태와 화면으로 원복된다.
- **AC4**: 화면에 표시되는 텍스트와 버튼 색상은 변수로 중복 저장하지 않고 `_isCompleted`를 통해 실시간 계산한다.

## 5. 검증 방법
- 앱 구동 후 초기 화면 캡처 (AC1 검증)
- 완료 버튼 클릭 후 변경 화면 캡처 (AC2 검증)
- 취소 버튼 클릭 후 원복 화면 캡처 (AC3. AC4 검증)
